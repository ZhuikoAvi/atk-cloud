# atk-cloud — облако Avito Toolkit Pro на GitHub

Бесплатная замена облачных функций сайта zhuiko.pro (когда он недоступен или чтобы не тратить его лимиты):

- **Ставки по расписанию и контроль лимитов** — каждые 5 минут, даже когда компьютер выключен.
- **Копии фидов автозагрузки** — `https://<владелец>.github.io/atk-cloud/feed/<id>.xml`.

Всё, что прислала программа (ключи Авито, расписание, ставки), лежит здесь **только зашифрованным**
(AES-256-GCM). Ключ расшифровки — секрет репозитория `ATK_VAULT_KEY`, он есть только у вас.

## Подключение (один раз)
1. Settings → Secrets and variables → Actions → **New repository secret**: `ATK_VAULT_KEY` — ключ из программы
   («Ставки» → «Облако на GitHub…» → «Копировать ключ»).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `pages`, папка `/ (root)`.
3. В программе вставьте токен GitHub (доступ к этому репозиторию: Contents и Actions — Read and write)
   и нажмите «Подключить».
